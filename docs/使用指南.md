## 0. 先做一次环境加载

```bash
cd ~/go2_official_ws
source scripts/setup.sh
```

这一步会：source ROS 2 Humble → source 官方 `unitree_ros2` 的 CycloneDDS → source 本工作空间 →
按网卡生成 `CYCLONEDDS_URI`，最后打印一行摘要：

```
[go2_env] WS=/home/seven/go2_official_ws SITES=.../sites IFACE=enp3s0 DOG=192.168.123.161（GO2_IFACE=xxx 可覆盖）
```

接机器狗时显式指定网卡（默认自动取默认路由网卡，可能取错）：

```bash
GO2_IFACE=enp3s0 source scripts/setup.sh
```

嫌吵加 `GO2_ENV_QUIET=1`。

## 路线 A：离线闭环演示（不需要机器狗）

用假数据把**生产同一条链路**整跑一遍：造地图/语音 → 站点资产校验 → 站点落地并生成站点 Nav2 参数 →
起巡检栈（感知/驱动/Nav2/巡检/播报）→ 逐点自动验收。

不需要机器狗、不需要 Gazebo、不需要现场地图。

### A1. 跑一轮自动验收

```bash
tools/offline_demo/run_patrol_demo.sh
```

约 2 分钟。成功时打印：

```
================ 离线闭环演示结果 ================
预期点位 : home -> zone_ne -> zone_se -> zone_sw -> zone_nw -> equipment_zone -> home
实际到达 : home -> zone_ne -> zone_se -> zone_sw -> zone_nw -> equipment_zone -> home
播报记录 : home, zone_ne, zone_se, zone_sw, zone_nw, equipment_zone
累计行程 : 23.71 m
总耗时   : 110.3 s
  [ OK ] 目标序列全部到达
  [ OK ] 累计行程 ≥ 5m
  [ OK ] 语音链路被触发
结论     : 通过（全部目标点到达）
==================================================
[demo] 验收通过 ✅
```

它实际验的是四件事：

1. **到点顺序**——是否按 `waypoints.yaml` 的顺序全到；
2. **到点精度**——每个点的 AMCL 位姿与目标点误差是否 ≤ 0.40m；
3. **累计行程**——是否真的走够了距离（默认 ≥ 5m，防止"原地抖动也算过"）；
4. **语音链路**——到点是否真的下发了播报。

退出码 0 = 通过，失败时给出原因，报告同时写到 `/tmp/go2_offline_demo/report.json`（路径见输出的最后一行）。

### A2. 带界面看过程

```bash
tools/offline_demo/run_patrol_demo.sh --rviz --loops 0 --keep
```

会打开 RViz 巡检视图，机器人一圈一圈跑。视图里能看到的：

| 显示项 | 话题 | 看什么 |
|---|---|---|
| Map | `/map` | 静态地图（演示用的是脚本生成的小房间） |
| GlobalCostmap / LocalCostmap | `/global_costmap/costmap`、`/local_costmap/costmap` | 膨胀圈是否合理、有没有把可走区域堵死 |
| LaserScan | `/scan` | 感知输出的红点 |
| GlobalPlan / LocalPlan | `/plan`、`/local_plan` | 规划路径与控制器实际跟踪的轨迹 |
| AMCLPose / ParticleCloud | `/amcl_pose`、`/particle_cloud` | 定位结果与粒子收敛情况 |
| Odometry | `/odom` | 里程计 |
| **WaypointMarkers** | `/waypoints/markers` | **巡检点位状态（重点看这个）** |

点位球的状态配色：

| 颜色 | 含义 |
|---|---|
| 绿 | 本圈已到达 |
| 黄 | 当前正在前往的目标 |
| 蓝 | 本圈还没访问 |
| 红 | 返航点（低电量 / 收工返航时高亮） |

看着它从「全蓝 → 一个一个变绿、当前的变黄 → 跑完一圈全部复位回蓝」，就说明巡检调度、
导航、到点判定整条链路都是活的。

看完停掉：

```bash
tools/offline_demo/run_patrol_demo.sh --clean
```

### A3. 换个场景验

```bash
# 低电量返航：跑 60 秒后把电量跳到 15%，看是否中断巡检并回 home
tools/offline_demo/run_patrol_demo.sh --battery-drop-after 60

# 绕障：房间中间补一个 0.6×0.6 的箱子
tools/offline_demo/run_patrol_demo.sh --obstacles "0.5,0,0.6,0.6,0.6"

# 不返航收工
tools/offline_demo/run_patrol_demo.sh --no-return-home

# 改超时（慢机器/想跑多圈）
tools/offline_demo/run_patrol_demo.sh --loops 3 --timeout 900

# 复用上一次生成的站点（跳过 apply_site，调参数时省时间）
tools/offline_demo/run_patrol_demo.sh --no-apply
```

全部参数：`tools/offline_demo/run_patrol_demo.sh --help`

### A4. 这个演示和 `run_demo.sh` 有什么区别

| | `run_demo.sh` | `run_patrol_demo.sh` |
|---|---|---|
| 目的 | **建图**演示：看地图怎么长出来 | **巡检**闭环演示：能不能交付 |
| 链路 | 假狗 + SLAM Toolbox + RViz | 生产同一套 `run_site.sh` + 站点参数 |
| 结果 | 肉眼看 | **自动断言 + 退出码** |

两个都要求在 WSL 的家目录副本里跑（`run_demo.sh` 里写死了 `$HOME/go2_official_ws`）。

## 路线 B：让真机器狗跑起来

### B1. 连线与连通性自检

网线接机器狗，确认网卡名（`ip link`），然后：

```bash
GO2_IFACE=<你的网卡名> source scripts/setup.sh

ros2 topic hz /lf/sportmodestate        # 运动状态，约 50Hz
ros2 topic hz /utlidar/cloud_deskewed   # 机载雷达点云（L2 约 5.5Hz，L1 约 11Hz）
```

两个都有频率，才说明 DDS 选网卡选对了、能收到机器狗的数据。没有频率先看
`完整部署与使用手册.md` 的「点云没有频率」。

### B2. 建图（每个站点做一次）

```bash
ros2 launch go2_patrol_bringup mapping.launch.py
```

用遥控器**慢速**走完整个要巡检的闭环（别贴墙、别原地急转），回到起点附近后：

```bash
./scripts/save_map.sh office_floor
```

地图会存到 `src/go2_patrol_bringup/maps/office_floor.pgm|.yaml`。
作为默认地图就把它改名成 `map.yaml`/`map.pgm`，或者启动时 `map:=<路径>` 指定。

### B3. 导航单点测试

```bash
ros2 launch go2_patrol_bringup navigation.launch.py
```

在 RViz 里：

1. **2D Pose Estimate** 点一下机器人的实际位置和朝向（给 AMCL 初始位姿）；
2. 等粒子云收敛到机器人身上（不要一上来就给目标）；
3. **2D Goal Pose** 给一个近处的点，确认能规划能走。

速度上限、急停距离这些先在低位验证，见 `完整部署与使用手册.md` 第 11 节。

### B4. 巡检 + 语音

1. 编辑 `src/go2_patrol_bringup/config/waypoints.yaml`（顺序就是巡检顺序）：

```yaml
waypoints:
  - name: entrance          # 点名，也是日志/标记里的名字
    x: 0.0                  # map 坐标系下的位置（米）
    y: 0.0
    yaw: 0.0                # 目标朝向（弧度）
    dwell: 4.0              # 到点停留秒数
    speech: entrance        # 语音 ID → audio/entrance.wav
    home: true              # 标记为返航点（只能有一个）
```

2. 把语音文件放进 `src/go2_patrol_patrol/audio/<speech_id>.wav`
   （仓库里只有 `README.md`，`.wav` 不进 git，需要你自己录/生成）；
3. 启动：

```bash
ros2 launch go2_patrol_bringup patrol.launch.py
```

手动干预：

```bash
ros2 service call /patrol/start  std_srvs/srv/Trigger   # 开始
ros2 service call /patrol/pause  std_srvs/srv/Trigger   # 暂停
ros2 service call /patrol/resume std_srvs/srv/Trigger   # 继续
ros2 service call /patrol/stop   std_srvs/srv/Trigger   # 停止
```

常用 launch 参数：`loops`（圈数，0=无限）、`return_home`（默认 true）、`battery_low`（低电量阈值，
默认 20%）、`arrival_tolerance`（到点容差，默认 0.30m）、`rviz`、`map`、`params_file`、
`waypoints_file`、`audio_dir`。

### B5. 采集航点

懒得手填坐标时，把狗开到位置再采：

```bash
ros2 run go2_patrol_patrol record_waypoint entrance
```

它会打印一段可直接粘进 `waypoints.yaml` 的 YAML，你再补 `speech` 和 `dwell`。

### B6. 上真机前的确认清单

- [ ] `GO2_IFACE` 指的是**接机器狗那张网卡**（多网卡机器容易选错）
- [ ] `/lf/sportmodestate`、`/utlidar/cloud_deskewed` 都有频率
- [ ] TF `base_footprint → base_link` **只有一处**在发布（机器人自己发了就别再补，否则 Nav2 报 TF 冲突）
- [ ] 启动时给了正确的初始位姿（仓库默认 `set_initial_pose: false`，需要人工给）
- [ ] 到点语音文件存在且能播：`aplay src/go2_patrol_patrol/audio/home.wav`
- [ ] 急停/遥控器在手，速度上限按现场地面复核过

## 路线 C：交付到另一台机器狗

完整流程与验收清单见 [`生产交付手册.md`](生产交付手册.md)，最常用的三条：

```bash
# 1) 生产机：装到 /opt/go2/releases/<版本>，切 current，装 systemd 单元
sudo deploy/install.sh --ref v0.1.0 --iface enp3s0

# 2) 落站点资产（地图/点位/语音/site.yaml）并生成站点参数
sudo deploy/apply_site.sh --site-dir /media/usb/site-office --name office

# 3) 开机自启 + 崩溃自动重启
sudo systemctl enable --now go2-patrol@office
```

日常运维：

```bash
systemctl status go2-patrol@office          # 状态
journalctl -u go2-patrol@office -f          # 实时日志
sudo systemctl restart go2-patrol@office    # 重启
deploy/install.sh --rollback <旧版本>        # 秒级回滚（站点资产不动）
```

站点之间的差异全部集中在站点 `site.yaml`（固定起点初始位姿、巡检参数、网卡、是否开 RViz），
升级只切 `/opt/go2/current` 软链。

## 4. 改代码与自检

```bash
cd ~/go2_official_ws
source /opt/ros/humble/setup.bash

colcon build --symlink-install                        # 全量
colcon build --symlink-install --packages-select go2_patrol_patrol   # 只编一个包
python3 -m pytest src/go2_patrol_patrol/test/ -q      # 单元测试（13 个）
tools/offline_demo/run_patrol_demo.sh                 # 端到端验收
```

**改完至少跑到哪一步**：

| 改动 | 至少验证 |
|---|---|
| `patrol_sequence.py` | `pytest` |
| `patrol_manager.py` / 巡检参数 | `run_patrol_demo.sh`（可加 `--battery-drop-after`） |
| 感知/驱动/Nav2 参数 | `run_patrol_demo.sh --rviz` 肉眼看 + 无头验收 |
| 部署脚本 `deploy/*` | `run_patrol_demo.sh`（它就是走 `deploy/apply_site.sh` + `deploy/run_site.sh`） |

CI：push 到 `main` 或开 PR 时会跑 GitHub Actions（Humble 上 `colcon build` + `colcon test`），
只在功能分支上 push 不会触发。

| 我想… | 命令 |

| 看效果（无机器狗） | `tools/offline_demo/run_patrol_demo.sh` |

| 清理演示进程 | `tools/offline_demo/run_patrol_demo.sh --clean` |
| 建图 | `ros2 launch go2_patrol_bringup mapping.launch.py` |
| 存地图 | `./scripts/save_map.sh <名字>` |
| 导航 | `ros2 launch go2_patrol_bringup navigation.launch.py` |
| 巡检 | `ros2 launch go2_patrol_bringup patrol.launch.py` |
| 采集航点 | `ros2 run go2_patrol_patrol record_waypoint <名字>` |

| 起一个生产站点 | `deploy/run_site.sh <站点名>` |

### 5.2 排错速查

| 现象 | 先查什么 |
|---|---|
| 收不到机器狗数据（话题没频率） | `GO2_IFACE` 是不是接狗那张网卡；`ip link` 看网卡名 |
| Nav2 起不来，日志有 `parameter ... is not initialized` | `nav2_params.yaml` 是否缺 `map_server.yaml_filename` 段 |
| Nav2 起不来，日志有 `has invalid type` | `controller_plugins` / `goal_checker_plugins` 必须是数组 `[FollowPath]` |
| **Nav2 一启动就整栈崩（段错误）** | `local_costmap.plugins` 里声明的插件是否都有对应配置块（尤其 `inflation_layer`） |
| 导航目标必失败、日志 `Empty Tree` | `bt_navigator.default_nav_to_pose_bt_xml` 不能是空串，删掉这一行 |
| TF 报冲突 / Nav2 抱怨多个父节点 | `base_footprint → base_link` 是否被重复发布 |
| 到点没声音 | 日志搜 `audio not found`；`aplay <文件>` 能不能直接播 |
| 定位漂移、乱走 | 固定起点有没有被挪、地图是否过期、是否给了初始位姿 |
| 服务反复重启 | `systemctl status` 看 `StartLimitBurst`；多半是参数/资产硬错误 |
| 演示跑完有残留进程 | `tools/offline_demo/run_patrol_demo.sh --clean` |

更完整的排查表：`生产交付手册.md` 第 10 节、`完整部署与使用手册.md` 第 13 节。

## 6. 目录导航

| 路径 | 干什么的 |
|---|---|
| `src/go2_patrol_driver/` | 官方 `sportmodestate` → TF/odom/imu；`/cmd_vel` → 运动请求；电量；急停 |
| `src/go2_patrol_bringup/` | 点云转 `/scan`、SLAM、Nav2 参数、launch、RViz 视图、地图 |
| `src/go2_patrol_patrol/` | 巡检调度、航点模型、录音播放、采集航点、单测 |

| `tools/offline_demo/` | 离线闭环演示（造数据 + 假狗 + 验收） |
| `deploy/` | 生产交付工具包：安装、站点落地、systemd、发布包、预检 |
| `scripts/` | 开发用：`bootstrap.sh` 一次性装环境、`setup.sh` 加载环境、`save_map.sh` 存地图 |
| `docs/` | 本指南 + 小白上机手册 + 完整手册 + 生产交付手册 + 环境搭建记录 + 选型对比 |
| `sites/` | 站点资产落地目录（**不进 git**，生产机由 `/etc/go2/site.env` 指定） |
